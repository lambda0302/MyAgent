# 类 Codex 自托管 Agent 项目技术栈调研报告

> 调研时间：2026-08-06
> 调研对象：GitHub 上带 GUI 的类 Codex Agent 项目（编码 Agent / 自托管 Agent 平台 / Agent 框架的 GUI 形态）
> 调研方式：GitHub API（实时拉取仓库配置）+ WebSearch 交叉验证

## 一、结论先行

在"**自托管 + 自带完整 Web GUI + 前后端分离 + 实时渲染 Agent 执行状态**"这个目标形态下，三个项目是主要参照系：

| 参照系 | 项目 | 前端 | 后端 | 实时通道 | 代码执行沙箱 |
|---|---|---|---|---|---|
| **编码 Agent 完整形态** | **OpenHands**（~83k★） | React 19 + Vite + Tailwind + HeroUI + Monaco + xterm.js | Python FastAPI + LiteLLM | **Socket.IO** | Docker 容器 |
| **可视化编排形态** | **AutoGPT Platform**（~186k★） | Next.js 15 + React + React Flow + Vercel AI SDK | Python FastAPI + Prisma(PG) + Redis + RabbitMQ | **WebSocket** + AI SDK 流式 | e2b / stagehand |
| **工具调用可视化形态** | **Cherry Studio**（Electron） | React 19 + React Flow + Tailwind | Electron 主进程 + Elysia + SQLite | 本地进程 | 本地 + ONNX |

技术栈高度收敛：前端清一色 **React + TypeScript + Vite + Tailwind**；后端 Python 系 **FastAPI**、JS 系 **Node/Express**；实时通讯 **Socket.IO 为主流**；代码/工具执行可视化分"节点图、工具卡片时间线、OTel trace"三条路线。

## 二、类 Codex 编码 Agent 项目

### 1. OpenHands（原 OpenDevin）— 最完整参照
- **仓库**：`OpenHands/OpenHands`，~83k★，MIT。已拆为前端仓库 + `software-agent-sdk`(Python 后端) + 云版。
- **前端**：React 19、react-router、Vite、Tailwind 4、HeroUI、Monaco Editor（代码）、xterm.js（终端）、socket.io-client、zustand、TanStack Query、framer-motion。桌面端用 Electron。
- **后端**：Python + FastAPI、LiteLLM（统一 LLM 接入）、pydantic。
- **代码执行**：Docker 沙箱容器。
- **实时**：Socket.IO 推送会话流、agent 状态、终端、文件树。
- **结论**：最贴合"自托管类 Codex + Web GUI"，建议作为第一参照。

### 2. AutoGPT Platform
- **仓库**：`Significant-Gravitas/AutoGPT`，~186k★。活跃部分是 `autogpt_platform/`。
- **前端**：Next.js 15 + React 18 + Tailwind + @xyflow/react(React Flow) + Radix UI + Vercel AI SDK + TanStack Query。
- **后端**：Python FastAPI + Uvicorn、Prisma(PostgreSQL)、Redis、RabbitMQ、独立 executor、多模型 SDK（OpenAI/Anthropic/Ollama 等）、mem0/graphiti 记忆。
- **实时**：WebSocket（后端独立 ws 进程）+ AI SDK 流式。
- **GUI**：可视化 Agent 流程图画布（节点运行状态着色）、实时日志、运行历史。
- **注意**：现在更偏"agent 工作流平台"，含强代码执行能力。

### 3. Cline（原 Claude Dev）
- **仓库**：`cline/cline`，~66k★，TypeScript，Bun monorepo。
- **形态**：VS Code 扩展 + `@cline/cli` 终端版 + **cline-hub 浏览器仪表盘**（live clients/sessions/streaming chat）+ SDK。
- **前端**（webview）：React + Vite + Tailwind + HeroUI/Radix + mermaid。
- **引擎**：TypeScript `@cline/core`（agent 循环、工具、MCP、permissions），本机执行带审批。
- **结论**：IDE 扩展形态，但自带 Web 浏览器仪表盘，工具调用 UI 值得参考。

### 4. Roo Code
- **仓库**：`RooCodeInc/Roo-Code`，~24k★，Apache-2.0。**2026 年已归档**，仅作历史参考。
- **形态**：VS Code 扩展（Cline 分叉），多角色 agent（Architect/Code/Ask），TypeScript。

### 5. SWE-agent
- **仓库**：`SWE-agent/SWE-agent`，~20k★，Python。
- **后端**：Python + litellm + rich/textual(TUI) + flask + flask-socketio(Web 界面) + swe-rex(Docker 沙箱)。
- **GUI**：主交互是 Textual 终端 TUI，附简单 Web 界面。默认跑"GitHub issue → 自动修 PR"流水线。

### 6. Aider
- **仓库**：`Aider-AI/aider`，~48k★，Python。
- **技术栈**：litellm + prompt-toolkit(TUI) + GitPython + grep-ast。
- **GUI**：纯终端 TUI，无自带 Web GUI；社区有第三方前端。

### 7. Open Interpreter
- **仓库**：`openinterpreter/open-interpreter`，~67k★。**已用 Rust 重写**（基于 OpenAI Codex 的 codex-rs）。
- **形态**：终端 CLI/TUI，兼容 Codex exec protocol 与 ACP，原生沙箱。无 Web GUI。
- 桌面端 `01-app`（TypeScript）与主仓库分离。

### 8. GPT Engineer
- **仓库**：`AntonOsika/gpt-engineer`，~55k★，Python，**已归档**（Lovable 前身）。纯 CLI，无 GUI。

## 四、Agent 框架的 GUI 形态

| 项目 | GUI 形态 | 前端 | 后端 | 运行可视化 |
|---|---|---|---|---|
| **AutoGen Studio**（微软） | 官方 Web 应用（随框架） | Gatsby + React + React Flow + antd | Python FastAPI + SQLite | 节点图 + 聊天流 + 工具日志 |
| **LangGraph Studio** | Web Studio + 已停更桌面端 | 闭源（Web 版 React） | langgraph runtime（FastAPI） | 图节点 + State 检查 + checkpoint 时间线 |
| **AgentScope**（阿里） | 官方 Studio（本地 Web） | React 19 + Vite + antd + tRPC + recharts | Python FastAPI + OTel；Studio 用 Node | OTel trace / 时间线 / 图表 |
| **CrewAI** | OSS 无 GUI（TUI + plot），商业 AMP/Crew Studio 闭源 | 商业闭源 | 纯 Python | 事件总线 + TUI |
| **Agno**（原 Phidata） | Playground/AgentOS，控制面托管 | React（闭源 npm 包） | Python FastAPI | 聊天流 + 工具调用 + 审批 |
| **Khoj** | 多端官方前端（Web/Electron/Obsidian/Emacs） | Next.js 15 + React + shadcn；Electron | Python Django | WebSocket 聊天流 + 图 |
| **Cherry Studio** | Electron 桌面客户端 | Electron + React 19 + React Flow | Electron 主进程 + Elysia + SQLite | **工具调用卡片 + Agent 执行时间线** |
| **Continue.dev** | IDE 扩展（Webview）+ CLI | React 18 + Vite + Redux | TypeScript/Node core 进程 | 聊天流 + 步骤卡片 + diff |

**共性**：
- 自带 GUI 的框架前端几乎清一色 React + TypeScript + Vite/Tailwind；图可视化大量用 **React Flow（@xyflow/react）+ dagre** 或 **mermaid**。
- 运行状态可视化三条主流路线：
  1. 节点/流程图（AutoGen、LangGraph、AgentScope）
  2. 聊天流 + 工具调用卡片/时间线（Cherry Studio、Continue、Khoj、Agno）
  3. OpenTelemetry trace 时间线（AgentScope、Agno、CrewAI 事件系统）
- 无内置 GUI 的框架通常靠 **FastAPI 暴露流式端点 + 自建 React 前端**，或 Streamlit/Gradio 快速套壳。

## 五、自建项目技术选型建议

综合三个调研，面向"**自托管 + Web GUI 的类 Codex 编码 Agent**"：

### 推荐主栈
| 层 | 选型 | 理由 |
|---|---|---|
| 前端框架 | **React 19 + TypeScript + Vite** | 生态最成熟，参照项目最多 |
| UI 组件 | **Tailwind CSS + shadcn/Radix UI** | OpenHands/AutoGPT/Langflow 主流 |
| 代码编辑 | **Monaco Editor** | 编码 Agent 展示/编辑文件 |
| 终端 | **xterm.js** | OpenHands 同款 |
| 图/拓扑 | **@xyflow/react + @dagrejs/dagre**（可选） | 任务/步骤可视化，AutoGen/Langflow 同款 |
| 实时通讯 | **Socket.IO**（或原生 WebSocket） | OpenHands/Open WebUI 主流，事件驱动 |
| 后端框架 | **Python FastAPI + Uvicorn + Pydantic** | LLM 生态最好，参照项目最多 |
| LLM 接入 | **LiteLLM**（统一多模型）或 `anthropic`/`openai` SDK | LiteLLM 一行切换 OpenAI/Anthropic/Ollama |
| 状态管理 | zustand + TanStack Query | 参照项目一致 |
| 数据库 | **SQLite（默认）+ SQLAlchemy**，可升 PostgreSQL | 自托管低成本起步 |
| 代码执行 | 本地 shell（带权限审批）→ 可选 Docker 沙箱 | MVP 先本地，后续加沙箱 |
| 部署 | Docker Compose（前端 + 后端 + 可选 DB） | 所有参照项目标配 |

### 推荐功能雷达（MVP → 完整版）
1. **会话流**：流式输出（SSE/WebSocket），Markdown + 代码高亮 + diff 渲染
2. **Agent 循环**：工具调用（read/write file、bash、grep/glob、web search）+ 权限审批
3. **工具调用可视化**：每个工具调用渲染为卡片/步骤，展示参数、结果、耗时
4. **文件树 + Monaco 代码查看**（可编辑）
5. **xterm 终端面板**（可选，实时 shell）
6. **会话历史持久化 + 断点恢复**
7. **多模型切换**（Anthropic / OpenAI / 本地 Ollama）
8. **任务/步骤流程图**（进阶，React Flow）
9. **Docker 沙箱执行**（进阶）
10. **MCP 支持**（进阶）

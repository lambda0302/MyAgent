## 验收总则

1. 项目可正常启动（前端 + 后端），提供 README 说明启动步骤。
2. 无阻断性报错；后端日志可定位问题。
3. 通过下方清单后，把本文件复制的验收结果（勾选项 + 截图/日志）回传给用户确认。
